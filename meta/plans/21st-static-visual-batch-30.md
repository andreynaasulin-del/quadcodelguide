# Publish 30 additional 21st.dev static visual guides

## Goal
Publish 30 additional distinct static visual guides sourced from current public 21st.dev projects.

## Rules
- Exclude every ID already present in `ui_views/guides.json`.
- Reject buttons, tables, form controls, dashboard clones, generic pricing cards and repeated compositions.
- Prefer typography, posters, editorial layouts, brand systems, data visuals and spatial compositions.
- Keep each selected work visually distinct; no duplicate visual families filling the batch.
- Require one usable preview per guide and use it once as the honest final result.
- Convert previews to optimized, self-hosted WebP files.
- Remove author names, source URLs and external attribution from published guide data.
- Do not modify unrelated local work.

## Checklist
- [x] Fetch at least 120 unseen public candidates
- [x] Reject UI controls, tables and duplicate visual patterns
- [x] Select 30 distinct static works
- [x] Download and convert previews to local WebP
- [x] Merge 30 guide records
- [x] Validate unique IDs, schema, local assets and attribution
- [x] Commit and push only the batch files
- [x] Verify production count and all 30 IDs
