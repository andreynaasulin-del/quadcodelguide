# Guide kits — доработка без саб-агента

STATUS: ready_for_live_test
CONTEXT: PO решил не использовать саб-агент; задача добита одним исполнителем.
52 кита пересобраны и залиты. Осталось только живое открытие в IDE.

## Что сделано

### 1. Одна кнопка
- Убрана вторая кнопка `Open in IDE` и обработчик `data-qc-ide`.
- Sticky CTA стал `<button>` и вызывает ту же функцию, что и основная.
- Подсказка под кнопкой переписана без упоминания «Open in IDE».

### 2. Deep-link handoff
- IDE запущена → сразу `/open-project`.
- IDE не запущена → открываем приложение, поллим `/ping` до 45 с и шлём проект
  автоматически.
- Тосты на таймаут и на ошибку `/open-project`.
- `message_raw` без `[Uploaded Image: …]` маркеров.

### 3. Медиа в чате IDE
- Исследован реальный формат USER-сообщений: `[Uploaded Image: path]` + base64
  в `images_data[path]`.
- LLM-ответы копируют этот формат для постеров/кадров.
- Видео/аудио в чате — текст + открытый файл в File editors.

### 4. Workspace
- `windows_state.json` открывает README + финальный файл (видео/картинка активна).
- `gui_state.json`: правая панель = File editors, дерево развёрнуто по `result/`,
  `prompts/`, `sources/`.
- `additional_context.yaml` и `mcp_ide_server.yaml` заполнены под каждый кит.

### 5. Виджеты
- snap01: HTML + GLB + постеры шипятся в `sources/`, пути переписаны относительно.
- README предупреждает про `file://` и даёт команду `python3 -m http.server 8000`.

### 6. Имена и агенты
- `agentForGuide` — по финальному медиа/категории/моделям.
- `projectNameFor` — обрезка по клаузе, без обрубка посередине фразы.

### 7. Утечки автора
- Не тащим реальные чаты, открытые табы, браузеры, консоли автора.
- `filters.yaml` сбрасываем до пустого whitelist.

### 8. Кэш
- `zip?v=<md5_10>` в `guides.json`.
- Blob zip-архивы заливаются с `cacheControlMaxAge: 300`.

## Результат пересборки
- 52/52 китов пересобраны и залиты.
- `ui_views/guides.json` обновлён.
- Браузерная проверка landing: одна кнопка, sticky CTA, нет JS-ошибок.
