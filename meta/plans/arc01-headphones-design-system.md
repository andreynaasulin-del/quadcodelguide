# ARC/01 — Senior Headphones Design System

## Goal
Create a premium, coherent launch system for original ARC/01 over-ear headphones using GPT-Image only. Every downstream asset must preserve one approved master product.

## Direction
- Product: premium closed-back over-ear headphones
- Character: precise, architectural, tactile; not futuristic cosplay
- Palette: warm aluminium, graphite leather, off-white studio, one coral signal accent
- Form signature: offset circular ear cups, exposed arc yoke, floating headband cushion, knurled control crown
- Typography mood: Swiss grotesk, technical annotations, restrained hierarchy
- Language: English only

1. [ ] Master product CGI — fixed object reference
2. [ ] Logo and wordmark system
3. [ ] Exploded construction view
4. [ ] Material and detail study
5. [ ] Desktop configurator UI
6. [ ] Mobile configurator UI
7. [ ] Landing-page hero
8. [ ] Campaign 16:9
9. [ ] Campaign 1:1

13. [ ] Final case-study board

## Consistency gates
- Same ear-cup proportions, yoke geometry, headband, crown and materials in every asset
- No AirPods Max silhouette, no existing brand marks, no extra controls
- Product reference remains the first image input for every product-bearing generation
- Text is English, sparse and verbatim
- UI must show plausible controls and accessible contrast
- Review each asset before continuing; reject any product drift

## Workflow
1. Generate and approve master product CGI
2. Derive identity from the product geometry
3. Build technical and material views from the master
4. Build desktop UI, then adapt to mobile
5. Build hero and campaign system from approved product + identity
6. Assemble final case-study board from approved outputs
