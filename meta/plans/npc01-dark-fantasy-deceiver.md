# NPC/01 — Design a Dark-Fantasy Deceiver

## Problem
Concept artists jump to face, costume and materials before the NPC can be recognized as a black shape. Result: pretty renders that fail silhouette tests, read as generic "vampire noble", and waste 3D budget on weak game readability.

## Product promise
Teach a production method for one original gothic/vampiric court NPC: lock narrative function → force readable silhouettes → pick one variant with a matrix → material/color → accessory logic → animation handoff pack.

## Locked direction
**Primary concept:** THE COURT PARASITE  
Original dark-fantasy deceiver. Not Loki, not Dracula cosplay. Thin court diplomat who feeds on influence, not blood theatrics.

## Production sequence
1. **Silhouette test** — three black silhouettes, no face/detail, same scale
2. **Pick winner** — matrix: authority / magic / threat / mobility
3. **Identity render** — full-body three-quarter with locked palette
4. **Turnaround** — front / 3-4 / side / back
5. **Expression + accessory sheet**
6. **Animation handoff** — idle, dialogue tell, spell cue, attack anticipation

## Visual system
- World: gothic court, dark fantasy, painterly cinematic game concept art
- Palette lock (Court Parasite): `#120F17` void / `#4A1830` dried blood / `#C7B79B` bone silk / cold steel accents
- Signature silhouette cues: bat-wing collar, long sleeve concealment, extreme vertical thinness
- English labels only on production sheets
- No copyrighted likenesses, no Marvel Loki, no Castlevania clones
